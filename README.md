# 🎬 Netflix Movies and TV Shows Analysis

**Data Visualization Final Project**

This project analyzes the **Netflix Movies and TV Shows** dataset using Python, Plotly, and Streamlit. The goal is to explore how Netflix's catalogue has evolved over time and present the findings through interactive visualizations and a dashboard.

---

## 📌 Project Objectives

- Analyze the growth of Netflix's catalogue over time.
- Compare Movies and TV Shows.
- Identify the top content-producing countries.
- Explore genres, audience ratings, and movie durations.
- Build an interactive Streamlit dashboard for data exploration.

---

## 📊 Dataset

**Dataset:** Netflix Movies and TV Shows (Kaggle)

🔗 https://www.kaggle.com/datasets/shivamb/netflix-shows

## 📈 Key Insights

- Netflix experienced rapid catalogue growth between **2016 and 2019**.
- Movies remain the dominant content type, while TV Shows have steadily increased.
- The United States contributes the highest number of titles, followed by India.
- Netflix offers a diverse collection of genres and content from many countries.
- Interactive visualizations make it easier to identify trends and patterns within the catalogue.
